# Financial Upload Format

CSV and XLSX uploads should include one row per company period.

Required columns:

- `company` or `company_name`
- `period`
- `fiscal_year`

Recognized labels include:

- `Revenue`, `Sales`, `Net Sales`, `Total Revenue`
- `A/R`, `Accounts Receivable`, `Trade Receivables`
- `Cash`, `Cash and Equivalents`
- `EBITDA`, `EBIT`, `Net Income`
- `Current Assets`, `Current Liabilities`
- `Inventory`, `Accounts Payable`
- `Total Debt`, `Debt`
- `Operating Cash Flow`, `Cash Flow from Operations`
- `Interest Expense`, `Capital Expenditure`
